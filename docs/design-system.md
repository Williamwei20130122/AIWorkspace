# 设计系统 · AIWorkspace 教学系统

## 1. 设计原则

1. **清晰优先**：教育场景信息密度中等，层级用字号/字重/色彩区分，不靠装饰。
2. **安静可信**：teal 主色传达稳定与专注；琥珀色只用于 CTA 与提醒，不大面积使用。
3. **扁平直接**：无渐变、无阴影；用边框、色块、留白构建层次。
4. **可扫读**：状态一律用徽章（未提交 / 已提交 / 已批改），日期统一格式。
5. **移动可用**：375px 宽度无横向滚动，主要操作可单手完成。

## 2. 色彩令牌

定义在 `src/app/globals.css` 的 `@theme` 中，Tailwind 里用 `bg-brand-600`、`text-ink-soft` 等。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `brand-600` | `#0D9488` | 主色：主按钮、图标、链接、品牌 |
| `brand-700` | `#0F766E` | 主色 hover |
| `brand-50` | `#F0FDFA` | 页面背景、选中态底 |
| `brand-100/200` | `#CCFBF1` / `#99F6E4` | 浅底、边框 |
| `accent` | `#D97706` | 强调 CTA（如「加入班级」「提交」） |
| `ink` | `#134E4A` | 主文字 |
| `ink-soft` | `#3F6B66` | 次文字、说明 |
| `surface` | `#F0FDFA` | 页面背景 |
| `card` | `#FFFFFF` | 卡片、侧栏 |
| `muted` | `#E8F1F4` | 弱化底色、禁用 |
| `line` | `#D5ECE8` | 边框、分隔 |
| `danger` | `#DC2626` | 错误、逾期 |
| `success` | `#0F766E` | 成功、已批改 |

状态色：已提交用 info 蓝 `#1D4ED8` 系；已批改用 emerald `#047857` 系；待办/临期用 amber `#B45309` 系；逾期用 red `#DC2626` 系。

## 3. 字体

- 西文/数字：**Plus Jakarta Sans**（Google Fonts，`globals.css` 顶部 `@import`；离线时回退系统字体）
- 中文：PingFang SC / Hiragino Sans GB / Microsoft YaHei
- 标题 600–700，正文 400–500；页面标题 24px，卡片标题 16px，正文 14–15px，辅助 12–13px
- 数字统计用 `tracking-tight` + 600 字重

## 4. 间距与圆角

- 间距刻度：4 / 8 / 16 / 24 / 32 / 48 / 64px（`--space-*` 对应 Tailwind 的 1/2/4/6/8/12/16）
- 卡片内边距 20px；页面左右 16–32px（随断点）
- 圆角：卡片 16px、按钮/输入框 10px、小按钮 8px、徽章/Avatar 全圆

## 5. 组件规范

| 组件 | 规范 |
| --- | --- |
| `Button`（primary） | teal 底白字，hover 深一档，禁用 55% 透明 |
| `Button`（secondary） | 白底 + `line` 边框 + teal 文字，hover 浅 teal 底 |
| `Button`（accent） | 琥珀底白字，用于「加入班级」「提交作业」等主 CTA |
| `Button`（danger） | 白底红字红边框，仅用于退出/删除类次要位置 |
| `Input/Textarea/Select` | 10px 圆角、1px 边框、focus 时 teal 边框 + 3px 外发光 |
| `Badge` | 12px、600 字重、全圆、浅底 + 同色系边框 |
| `Card` | 白底、16px 圆角、1px 边框、无阴影 |
| `StatCard` | 左侧 40px 图标块 + 标签 12px + 数值 24px 600 |
| `PageHeader` | eyebrow 12px 大写字距 + 标题 24px + 描述 14px + 右侧操作区 |
| `EmptyState` | 虚线边框、图标块、标题 + 说明 + 可选操作 |
| `Avatar` | 圆形、品牌色底、首字（中文取末字） |
| 侧栏 | 256px、白底右边框；选中项 `brand-50` 底 + `brand-700` 文字 |

## 6. 布局与响应式

- 桌面（≥1024px）：左侧 256px 固定侧栏 + 主内容区，页面最大内容宽度由栅格自适应。
- 平板/移动（<1024px）：顶部栏（品牌 + 菜单按钮）+ 抽屉导航；内容区单列。
- 列表页：桌面用卡片/表格，移动端改为堆叠卡片，避免横向滚动。
- 页面结构顺序：`PageHeader` → 统计卡（如有）→ 主内容区块。

## 7. 文案规范

- 全中文；按钮用动词短语（「创建班级」「提交作业」「保存批改」）。
- 状态词统一：未提交 / 已提交 / 已批改 / 已截止。
- 日期：`2026-11-08`；时间：`11-08 14:30`；截止提示：`今天截止`、`还剩 3 天`、`已截止`。
- 空状态给出下一步（如「还没有班级，先创建一个班级」）。
- 错误文案说明怎么办，不只说「失败」。

## 8. 可访问性

- 正文对比度 ≥ 4.5:1（ink `#134E4A` on `#F0FDFA` 达标；辅助文字不用于关键信息）。
- 所有交互元素有可见 focus 环（`:focus-visible` 2px teal）。
- 表单 `label` 与输入框用 `htmlFor/id` 关联；错误信息用 `role="status"`。
- 图标按钮必须有 `aria-label`；纯装饰图标 `aria-hidden="true"`。
- 颜色不是唯一信息载体：状态徽章同时带文字。

## 9. 交付前自检

- [ ] 无渐变/阴影；层级靠边框、底色、字号
- [ ] 页面只有一个 `h1`（`PageHeader`），卡片标题用 `h2`
- [ ] 375 / 768 / 1440 三档宽度检查无横向滚动
- [ ] 所有表单有 pending 态与错误提示
- [ ] 空状态、加载失败路径可读
- [ ] 颜色令牌全部来自 `@theme`，不写零散 hex
