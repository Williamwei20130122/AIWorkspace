# 需求说明 · AIWorkspace 教学系统（v3：课题 · 提交 · 评价）

- 版本：v3（课题-提交-评价模型）
- 更新：2026-11
- 状态：实现中（Go 后端 + TS 前端）

## 1. 背景与目标

学校需要一个不依赖第三方平台、可在校内网络自建部署的网页教学系统，围绕 **课题（Topic）→ 提交（Submission）→ 评价（Evaluation）** 的流程运转：

- 教师：创建课题、管理学生与助教、接收提交、多维评价。
- 学生：用老师分配的学号进入，查看课题介绍、提交作品（文本 + 任意文件）、查看评价。

目标：一个可运行的工程底座（账号、权限、数据模型、页面、Docker 部署），支撑真实课堂使用与后续迭代。

## 2. 用户与场景

| 角色 | 说明 | 核心诉求 |
| --- | --- | --- |
| 教师 | 用邮箱或手机号注册 | 建课题、管学生、收提交、快速评价 |
| 助教 | 被课题创建者邀请（≤3 人） | 协助管理学生与评价 |
| 学生 | 老师创建（默认用户名，无密码） | 看课题、交作品、看评价 |

典型场景：

- 王老师注册后创建「校园气象站数据记录」课题，把李老师加为助教，把 3 名学生加入课题；学生用学号直接进入，提交文本与观测数据文件；老师按「数据完整性 / 分析质量 / 规范表达」三个自定义维度打分并写评语；学生提交后被评价，不能再次修改。
- 张老师创建学生账号时发现用户名已存在，查看信息后确认是同一学生，选择「加入我的管理」，而不是重复创建。

## 3. 功能需求

### 3.1 账号与会话（P0）

- FR-1 教师用**邮箱或手机号**注册（自助注册页），密码 ≥8 位；登录框支持邮箱/手机号/学号。
- FR-2 学生账号由老师创建（姓名 + 默认用户名）；用户名全局唯一。
- FR-3 用户名冲突：展示已有账号信息（姓名、创建者、是否有密码）；同一人 → 加入我的管理；不同人 → 换用户名重新创建。
- FR-4 学生默认**无密码**，可凭用户名直接登录；学生可自行设置/清除密码；老师可重置/关闭密码，**任何地方不显示明文**。
- FR-5 会话：HttpOnly + SameSite=Lax Cookie，HMAC 签名，7 天有效；未登录跳登录页；角色不符跳对应首页。
- FR-6 一个学生可被多个老师管理；老师只能操作自己管理的学生。

### 3.2 课题（P0）

- FR-7 创建课题（标题、介绍页 Markdown）；编辑标题/介绍；关闭/恢复课题。
- FR-8 邀请助教（最多 3 人）；移除助教；创建者权限可移交（原创建者变为助教）。
- FR-9 学生加入/移出课题：由创建者或助教操作（被动加入）；学生不能自行加入/退出；移出保留历史，学生仍可查看历史课题与评价。
- FR-10 课题介绍页渲染 Markdown（学生端只读）。

### 3.3 提交（P0）

- FR-11 学生提交：文本（纯文本展示，不渲染 Markdown/LaTeX）+ 任意类型文件多文件上传（≤10 个，单文件 ≤100MB）。
- FR-12 未评价前可重新提交（覆盖文本与附件）；已评价后**禁止重新提交**（后端 400，前端禁用并提示）。
- FR-13 已关闭课题禁止提交。
- FR-14 学生可下载自己提交的附件；老师可下载所管理课题的附件。

### 3.4 评价（P0）

- FR-15 维度由课题定义（名称 + 满分），创建者/助教可增删改。
- FR-16 对提交评价：文字评语 + 各维度整数分数（0..满分）；一个提交可多次评价、历史保留。
- FR-17 教师评价汇总页：自己管理课题下的全部评价（时间倒序）。
- FR-18 学生评价页：自己全部历史课题的评价（时间倒序）。

### 3.5 系统（P0）

- FR-19 健康检查 `GET /api/health`。
- FR-20 空库首次启动写入演示数据；重启不重复。
- FR-21 Docker 单容器部署，宿主 3100 端口，`/data` 卷持久化（数据库 + 附件）。

### 3.6 本期不做（P1/P2）

- 阶段性评价、评价模板复用、表情/图像化评价
- 开放课题（学生自主加入）
- 通知与提醒、附件在线预览
- 管理员后台、多学校、导出统计
- 第三方登录

## 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 部署 | `docker compose up -d --build` 一条命令；无外部数据库依赖 |
| 端口 | 宿主机 3100，容器内 3100 |
| 数据 | SQLite + 附件目录在 `/data` 卷；重启不丢；`down -v` 重置 |
| 安全 | 口令 scrypt；会话 HMAC；HttpOnly Cookie；所有查询按用户过滤；上传文件名清洗；附件下载鉴权 |
| 性能 | 单机数百人内页面首屏 <2s（内网） |
| 兼容 | Chrome / Edge / Safari 最近两版；桌面优先，移动可用 |
| 可维护 | Go gofmt/vet；TS strict；接口契约文档化 |
